Tonneau dans l'eau

Maquettes avec les vraies textures du jeu (16 px, sans le lissage xBR). Le joueur pousse le tonneau dans l'eau, puis marche dessus. Aujourd'hui la case redevient du sol ; les variantes A, B et C gardent l'eau et montrent le tonneau qui affleure.
